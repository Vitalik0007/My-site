About the Game

This project serves as a technical sandbox, demonstrating how to configure the engine, implement branching dialogue, switch backgrounds and character sprites, and manage scenes using Naninovel’s scripting system. While not a full game, it provided a strong foundation for understanding how to develop narrative-driven experiences in Unity.

Technologies Used

  • Unity – game engine used for project structure and integration
  • C# – custom scripting for UI and gameplay logic
  • Naninovel – visual novel framework for dialogue, scenes, and scripting
  • Unity UI System – integration of custom menus and interaction elements
  • Text-based Scripting (Naninovel format) – for branching dialogue and scene control

My Role

I was fully responsible for setting up and experimenting with Naninovel in Unity. I handled engine configuration, created test scenes, implemented custom scripts for branching logic and UI, and explored how to extend the system for potential future use in narrative games. This project allowed me to quickly prototype ideas and gain practical experience with a specialized visual novel framework.
