About the Game

SlotsGame is a stylish and entertaining slot-machine-inspired game originally developed for a client. When the project was cancelled midway, I decided to complete and polish it as a personal project.

Technologies Used

  • Unity
  • C#
  • Leonardo.AI & Photoshop
  • Unity UI System

My Role

I was solely responsible for the entire development process — from implementing the slot machine logic and win detection system to designing the UI and structuring a clean, maintainable C# architecture. I focused on delivering polished gameplay mechanics and responsive user interaction.
