About the Game

Death Island is a fast-paced clicker game where players must defeat waves of enemies across 50 progressively challenging levels. The core mechanic revolves around tapping enemies to deal damage, while gradually upgrading auto-click features, damage boosts, and other enhancements. The game features a simple yet engaging progression system, in-game currency, and both rewarded ads and in-app purchases for monetization. Designed with accessibility in mind, it offers intuitive gameplay and satisfying feedback loops.

Technologies Used

  • Unity - Game engine used for building the game, managing the core mechanics, and gameplay features.
  • C# - Primary programming language used for scripting the game's logic and mechanics.
  • Firebase - Used for user authentication and account management, enabling sign-ups and logins.
  • Google Ads - Integrated for monetization through rewarded ads and ad placement.
  • In-App Purchases (IAP) - Integrated for handling in-game purchases and currency transactions.
  • Multilang Plugin - Used to add multiple languages, allowing the game to be localized for different audiences.
  • Photoshop - For creating and editing 2D graphics used in the game.

My Role

In Death Island, I was responsible for both gameplay programming and UI design, primarily focusing on integrating Firebase for user authentication and managing player accounts. I worked closely with a team to ensure smooth interaction between the game’s core mechanics and external services like Google Ads and In-App Purchases.
