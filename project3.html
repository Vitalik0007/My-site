About the Game

Join the rebellion! Outsmart the dictators in Despot Drain. It's time to flush out tyranny and restore freedom in this fun, addictive adventure. Ready to make a splash? Try it now to save the world and become the hero your nation needs!

Technologies Used

  • Unity – Main game engine used for development
  • C# - Primary programming language used for scripting the game's logic and mechanics.
  • Google Ads SDK – Integrated for rewarded and interstitial ads
  • Leonardo.AI & Adobe Photoshop – Used for generating and refining game artwork
  • Unity UI System – Custom interface for drawing mechanics and level flow
  • Custom Drawing System – Player-drawn paths implementation for fluid dynamics

My Role

I was responsible for the full development cycle: gameplay logic, custom path-drawing mechanics, animations, UI/UX design, artwork generation using Leonardo.AI and Photoshop, bug fixing, ad integration with Admob SDK, and deployment to Android.
