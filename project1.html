About the Game

The game is designed specifically for young children and aims to support early cognitive development through fun and interactive activities. It features a collection of carefully crafted mini-games that focus on essential skills such as color recognition, shape matching, memory, and logical thinking.

Technologies Used

  • Unity (C#) – Core game development engine
  • ScriptableObjects – Modular data architecture for mini-game configuration
  • DOTween – Smooth UI and gameplay animations
  • Spine Unity Runtime – Integration of animated character hints and elements
  • Unity UI (UGUI) – Responsive user interface layout and interaction

My Role

As the sole Unity developer on this project, I was responsible for implementing the full gameplay logic, building multiple mini-games from scratch, creating a flexible and reusable game architecture using ScriptableObjects, integrating UI animations with DOTween, and supporting animated hints using Spine. I collaborated with the game artist to ensure smooth user experience and age-appropriate interactions for young children.
