About the Game

Set in a world grappling with a viral outbreak, the game challenges players to strategically place medical buildings—such as pharmacies, hospitals, and vaccine labs—to stop waves of viruses from reaching civilians. Each virus type presents different stats and behaviors, while every building attacks using unique medical-themed projectiles like syringes, pills, and disinfectant bursts. The game blends strategy, progression, and a light educational theme into a cohesive and accessible gameplay experience.

Technologies Used

  • Unity – core engine for game development
  • C# – scripting and gameplay logic
  • Unity UI System – health bars, wave indicators, building menus
  • Custom Tower Defense Framework – wave management, projectile logic, placement system
  • Leonardo.AI & Adobe Photoshop – Used for generating and refining game artwork
  • Manual Level Design – limited build spots and wave balancing

My Role

I was solely responsible for the full development of VirusDefense, from concept and design to implementation and testing. I designed the entire gameplay loop, enemy and tower systems, wave logic, projectile mechanics, UI, and sound structure. The project showcases my ability to build a complete, functional game independently, applying both programming and game design principles in Unity.
